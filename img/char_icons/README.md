# 看板娘角色图标

看板娘「选择角色」面板用的头像 PNG，**文件名 = 三位角色号**。

## 现有图标

| 角色号 | 角色 | 来源 |
| --- | --- | --- |
| `041.png` | 高松 燈 | `MyGO/cg/灯/灯_Tomori.jpg` |
| `002.png` | 千早 愛音 | `MyGO/cg/爱音/愛音_Anon.jpg` |
| `029.png` | 要 楽奈 | `MyGO/cg/乐奈/楽奈_Rana.jpg` |
| `037.png` | 長崎 そよ | `MyGO/cg/素世/そよ_Soyo.jpg` |
| `039.png` | 椎名 立希 | `MyGO/cg/立希/立希_Taki.jpg` |

均为 174×174 真彩 PNG（控件显示尺寸 58×58，3 倍屏下仍清晰），
由 400×400 方形源图等比缩放而来，合计约 173KB。

角色号与名字的对应来自 `waifu.js` 里的 `ROLE_NAMES`，顺序为
041 高松燈 → 002 千早愛音 → 029 要楽奈 → 037 長崎そよ → 039 椎名立希。

## 为什么需要这个目录

`waifu.js` 里写死了：

```js
fabImg.src = ICON_BASE + roleNum(curRole) + '.png';   // → live2d/char_icons/041.png
```

但 `sakura-live2d` 项目**没有部署 `live2d/char_icons/` 和 `live2d/assets/`**，
这两个目录下的图标全部 404。那个项目是「直接上传」部署且没有关联 Git 仓库，
重新部署会把整个模型库覆盖掉，所以不能去那边补文件。

## 现在的做法（零 404）

由 `js/live2d-fix.js` 在客户端拦截：把命中那两个目录的地址换成**本站的**
`img/char_icons/<角色号>.png`（`HAS_REAL_ICONS = true`）。

> 为什么拦的是「地址」而不是「等失败了再换」：判断图标存不存在只能先发一次请求，
> 而请求失败浏览器必定在控制台留一条红色 404。拦截是从源头掐掉请求。

> 若把 `HAS_REAL_ICONS` 改回 `false`，会退回内联绘制的 SVG 占位头像
> （粉色渐变圆 + 角色号），一个图标请求都不发。

## 换图

直接覆盖同名 PNG 即可，无需改任何代码；新图建议仍用方形、174×174。
