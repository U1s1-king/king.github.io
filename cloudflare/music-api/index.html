🌸 樱花音乐 API

网易云音乐元数据网关 · Cloudflare Pages Functions · 无登录、无 Cookie、不收集数据

接口一览

GET /api/health健康检查
GET /api/search搜索 · keywords limit offset type(1歌曲/10专辑/100歌手/1000歌单)
GET /api/song/detail歌曲详情 · ids=1,2,3（最多 100 个）
GET /api/lyric歌词（含翻译/罗马音） · id
GET /api/playlist歌单详情 · id
GET /api/playlist/tracks歌单全部歌曲 · id limit offset
GET /api/toplist排行榜列表（63 个）
GET /api/recommend/playlist推荐歌单 · limit
GET /api/recommend/newsong推荐新歌 · limit
GET /api/catalogue歌单分类
GET /api/artist歌手详情 · id
GET /api/artist/songs歌手热门歌曲 · id limit
GET /api/url可播放地址（多镜像聚合） · id server
GET /api/url/lyric歌词兜底（多镜像） · id
GET /api/metingMeting 通用代理 · type server …
