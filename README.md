## SYSTEM / OVERVIEW

A static-first personal website built around small, focused spaces. Each page has its own purpose and visual identity, while the overall experience shares one consistent design language.

```text
ZHAOKENING
├── HOME       / Entry point
├── JOURNAL    / Notes and moments
├── ARCHIVES   / Things kept
├── MUSIC      / Sound and atmosphere
├── TOOLS      / Useful utilities
├── GAMES      / Play
└── TV         / Night-time viewing
```

## LOCAL DEVELOPMENT

```bash
git clone https://github.com/U1s1-king/king.github.io.git
cd king.github.io
node server.js
```

Open `http://127.0.0.1:8888` in your browser.

## DESIGN NOTES

- **Seven pages, seven visual identities.** Each animated SVG uses a visual metaphor suited to its destination.
- **The artwork is the navigation.** Every animated panel links directly to its page.
- **One shared visual language.** Sakura pink, quiet gradients, soft light and restrained digital motion.
- **Keep the implementation focused.** The README introduces the experience; the site itself holds the details.
