## Architecture

```text
                               USER
                                │
                                ▼
                     ┌─────────────────────┐
                     │      BROWSER        │
                     │ HTML · CSS · JS     │
                     └──────────┬──────────┘
                                │
          ┌─────────────────────┼─────────────────────┐
          │                     │                     │
          ▼                     ▼                     ▼
   ┌──────────────┐     ┌──────────────┐      ┌──────────────┐
   │ GitHub Pages │     │ Cloudflare   │      │ External APIs│
   │ Static Site  │     │ CDN · HTTPS  │      │ Music · Data │
   └──────┬───────┘     └──────┬───────┘      └──────────────┘
          │                    │
          ▼                    ▼
   ┌──────────────┐     ┌──────────────┐
   │Service Worker│     │Security Layer│
   │Cache/Offline │     │Headers / CSP │
   └──────────────┘     └──────────────┘

                       GUESTBOOK SYSTEM
                                │
                                ▼
                     ┌─────────────────────┐
                     │ Cloudflare Worker   │
                     └──────────┬──────────┘
                                │
             ┌──────────────────┼──────────────────┐
             ▼                  ▼                  ▼
            KV               JSONBin          Turnstile
         Rate Limit           Storage            Verify
```

## Security Layer

```text
ONLINE EDGE
│
├── CSP
├── HSTS
├── X-Content-Type-Options
├── X-Frame-Options
├── Referrer-Policy
└── Permissions-Policy

GUESTBOOK API
│
├── CORS Allowlist
├── Turnstile Verification
├── Input Sanitization
└── Rate Limiting

SECRETS
│
└── Keep API Keys / Tokens / Passwords outside Git
```

> **Rule #1：任何 API Key、Token、密码或 Secret，都不应该提交到仓库。**
